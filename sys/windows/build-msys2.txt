Compilation de NetHack avec MSYS2

(Traduction française du document d'origine build-msys2.txt.)

Prérequis :

  o  MSYS2
        - https://www.msys2.org/
        - Téléchargez et lancez l'installateur, puis démarrez le shell UCRT64.
     ensuite
          pacman -S mingw-w64-ucrt-x86_64-gcc
          pacman -S git
          pacman -S make
          pacman -S vim (ou l'éditeur de votre choix)
          pacman -S man (sinon « git help foo » ne fonctionnera pas)
          pacman -S perl-doc (sinon « git nhhelp foo » ne fonctionnera pas ;
                              nécessaire seulement si vous utilisez
                              nhgitset.pl)
  o Lua
  o pdcursesmod (requis seulement si vous voulez l'interface curses)
     La façon de les obtenir est expliquée plus loin dans ce fichier.

Composants requis qui ne sont pas fournis dans le dépôt NetHack, mais
qui sont nécessaires pour compiler NetHack vous-même.

Lua
        NetHack 5.0 pour Windows nécessite les sources de Lua, un projet
        tiers qui ne fait pas partie de la distribution ni du dépôt de
        NetHack.

        Un script shell bash permettant de récupérer les sources requises
        est disponible ; lancez-le comme suit depuis la racine de
        l'arborescence des sources de NetHack pour obtenir Lua :
            sh sys/windows/fetch.sh lua

Curses
        Si vous voulez inclure la prise en charge de l'interface curses
        dans NetHack 5.0, les sources de pdcursesmod, un projet tiers, sont
        nécessaires ; elles ne font pas partie de la distribution ni du
        dépôt de NetHack.

        Un script shell bash permettant de récupérer les sources requises
        est disponible ; lancez-le comme suit depuis la racine de
        l'arborescence des sources de NetHack pour obtenir pdcursesmod :
            sh sys/windows/fetch.sh pdcursesmod

Compilation

Deux versions différentes de NetHack pour Windows seront compilées en
ligne de commande avec l'approche par Makefile :
    une version tty utilisant le sous-système d'E/S console Win32,
    ainsi qu'une interface curses, dans un exécutable nommé NetHack.exe ;

    une version Win32 native, graphique, reposant sur l'API Windows,
    ainsi qu'une interface curses graphique, dans un exécutable nommé
    NetHackW.exe.

Les configurations de Makefile compilent à la fois NetHack.exe et
NetHackW.exe, qui pourront utiliser les mêmes fichiers de données, de
sauvegarde et d'os (bones).

Depuis la dernière version officielle de NetHack, les compilateurs et les
architectures ont évolué ; vous pouvez désormais choisir de compiler une
version x86 32 bits ou une version x64 64 bits. Le Makefile par défaut
est configuré pour une version x86 32 bits, uniquement parce qu'elle
fonctionnera sur le plus grand nombre d'environnements Windows existants.
Modifiez-le si vous le souhaitez. Sachez que les fichiers de sauvegarde
et d'os des versions 5.0 de NetHack ne sont pas interchangeables entre la
version 32 bits et la version 64 bits (ni entre plateformes différentes).

I. Dissiper les idées reçues :

    Compiler NetHack pour Windows n'est pas aussi facile qu'il y paraît,
    ni aussi difficile qu'on pourrait le croire ; il est toutefois
    préférable de lire toute cette section avant de commencer.

    Nous fournissons GNUmakefile dans sys/windows/GNUmakefile, à utiliser
    depuis le shell bash inclus avec MSYS2. Il s'appelle GNUmakefile car
    c'est le premier nom recherché par l'utilitaire GNU make, ce qui évite
    tout conflit avec le Makefile utilisé par l'utilitaire nmake de
    Microsoft.


II. Pour compiler votre copie de NetHack sur une machine Windows avec
    MSYS2 :

Préparation

1.  Placez-vous à la racine de l'arborescence des sources de NetHack, si
    ce n'est pas déjà le cas.

2.  Exécutez la commande suivante pour copier les Makefiles dans le
    sous-dossier src :
        cp sys/windows/GNUmakefile* src

3.  Placez-vous dans le sous-dossier src de l'arborescence des sources de
    NetHack. La commande suivante suppose que vous êtes toujours à la
    racine, comme aux étapes 1 et 2 ci-dessus :
        cd src

Compilation

4.  Maintenant que tout est en place, vous êtes prêt à lancer le
    processus.

    Votre répertoire courant doit être le répertoire src de NetHack.

    Lancez les commandes suivantes, qui trouveront et utiliseront
    GNUmakefile par défaut :

        make clean
        make depend
        make

    Si tout se passe bien, les fichiers intermédiaires de NetHack seront
    placés dans le sous-dossier binary de l'arborescence NetHack, et le
    paquet final de NetHack pour Windows sera dans le sous-dossier package.

Remarques :

1.  Pour recompiler NetHack après une modification, placez-vous dans src
    et lancez la commande suivante :
        make

2.  Une alternative à MSYS2 pourrait être MinGW-w64 - winlibs standalone
    build. Nous ne l'avons pas testée au moment de la rédaction.
        MinGW-w64 - winlibs standalone build
        - https://github.com/brechtsanders/winlibs_mingw
        - Téléchargez l'une des versions publiées depuis
          https://github.com/brechtsanders/winlibs_mingw/releases
          et extrayez son contenu dans un dossier (de préférence un dossier
          dont le chemin ne contient pas d'espaces), puis ajoutez à votre
          PATH l'emplacement du sous-dossier contenant gcc.exe.
