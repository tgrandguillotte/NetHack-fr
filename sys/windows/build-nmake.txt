Compilation de NetHack avec le nmake de Visual Studio en ligne de commande

(Traduction française du document d'origine build-nmake.txt.)

Prérequis :

  o Visual Studio Community
        Une copie de Microsoft Visual Studio Community doit être
        installée sur votre machine. Voir :
        https://visualstudio.microsoft.com/vs/community/


Les Makefiles et procédures de compilation produisent deux exécutables :
    a. une version TTY et curses de NetHack dans nethack.exe ;
    b. une version graphique Windows et curses dans nethackw.exe.

Vous pouvez utiliser l'un des environnements de compilation suivants :

Compilation

Deux versions différentes de NetHack pour Windows seront compilées en
ligne de commande avec l'approche par Makefile :
    une version tty utilisant le sous-système d'E/S console Win32,
    ainsi qu'une interface curses, dans un exécutable nommé NetHack.exe ;
        NetHack
    une version Win32 native, graphique, reposant sur l'API Windows,
    ainsi qu'une interface curses graphique, dans un exécutable nommé
    NetHackW.exe.

Les configurations de Makefile compilent les deux, NetHack.exe et
NetHackW.exe, qui pourront utiliser les mêmes fichiers de données, de
sauvegarde et d'os (bones).

Depuis la dernière version officielle de NetHack, les compilateurs et les
architectures ont évolué ; vous pouvez désormais choisir de compiler une
version x86 32 bits ou une version x64 64 bits. Le Makefile par défaut
est configuré pour une version x86 32 bits, uniquement parce qu'elle
fonctionnera sur le plus grand nombre d'environnements Windows existants.
Modifiez-le si vous le souhaitez. Sachez que les fichiers de sauvegarde
et d'os de la version 5.0.1 de NetHack n'ont pas encore suffisamment
évolué pour être interchangeables entre la version 32 bits et la version
64 bits (ni entre plateformes différentes). Cela pourrait changer à
l'avenir.

I. Dissiper les idées reçues :

    Compiler NetHack pour Windows n'est pas aussi facile qu'il y paraît,
    ni aussi difficile qu'on pourrait le croire ; il est toutefois
    préférable de lire toute cette section avant de commencer.

    Nous fournissons un Makefile pour le nmake de Visual Studio dans
    sys/windows/Makefile.nmake, à utiliser depuis la ligne de commande
    Windows.


II. Pour compiler votre copie de NetHack sur une machine Windows :

Préparation

1.  Placez-vous dans le sous-dossier sys\windows de l'arborescence des
    sources de NetHack, si vous êtes à la racine de cette arborescence.
        cd sys\windows.

2.  Exécutez
        .\nhsetup.bat
    pour copier les Makefiles dans le sous-dossier src. Le fichier
    sys\windows\Makefile.nmake sera copié dans un fichier src\Makefile.
        .\nhsetup.bat
3.  Exécutez
        .\fetch.bat lua
    pour placer une copie de Lua dans le sous-dossier lib de
    l'arborescence des sources de NetHack. NetHack 5.0 pour Windows
    nécessite les sources de Lua, un projet tiers qui ne fait pas partie
    de la distribution ni du dépôt de NetHack.

4.  Si vous voulez inclure dans votre compilation la prise en charge de
    l'interface curses (facultative), exécutez
        .\fetch.cmd pdcursesmod
    pour placer une copie de pdcursesmod dans le sous-dossier lib de
    l'arborescence NetHack.

5.  Placez-vous dans le sous-dossier src de l'arborescence des sources de
    NetHack. La commande suivante suppose que vous êtes toujours dans le
    dossier sys\windows, comme aux étapes 1 et 2 ci-dessus :
        cd ..\..\src

Compilation

6.  Maintenant que tout est en place, vous êtes prêt à lancer le
    processus.

    Votre répertoire courant doit être le répertoire src de NetHack.

    Lancez la commande suivante :
	    nmake package

    Si tout se passe bien, les fichiers intermédiaires de NetHack seront
    placés dans le sous-dossier binary de l'arborescence NetHack, et le
    paquet final de NetHack pour Windows sera dans le sous-dossier package.

Remarques :

N1. Pour recompiler NetHack après une modification, placez-vous dans src
    et lancez la commande adaptée à votre compilateur :

    Pour le compilateur Microsoft :
        nmake package

N2. Selon la compilation, le compilateur et les outils utilisés ci-dessus,
    le paquet produit contiendra :
      - soit un fichier .exe 32 bits (x86),
        qui devrait fonctionner sur tout environnement Win32 récent ;
      - soit un fichier .exe 64 bits (x64),
        qui devrait fonctionner sur tout système Windows 64 bits.

    **Remarque** : les parties sauvegardées et les fichiers d'os ne sont
    PAS compatibles entre les versions 32 bits et 64 bits pour l'instant.
