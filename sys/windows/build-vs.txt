Compilation de NetHack avec l'IDE Visual Studio

(Traduction française du document d'origine build-vs.txt.)

Prérequis :

  o Visual Studio Community
        Une version de Microsoft Visual Studio Community doit être
        installée sur votre machine. Il peut s'agir soit de la version pour
        Windows 11 x64, destinée aux machines à processeur Intel/AMD64,
        soit de la version pour Windows 11 ARM64, destinée aux machines à
        processeur ARM64 (Snapdragon).

        Vous pouvez choisir de compiler pour une cible x64 ou pour une
        cible ARM64, aussi bien avec la version x64 de Visual Studio
        qu'avec la version ARM64. Les versions de Visual Studio, depuis
        Visual Studio 26, savent compiler pour la plateforme hôte native et
        faire de la compilation croisée vers l'autre plateforme cible.

        Si vous voulez pouvoir faire de la compilation croisée pour les
        deux types de cibles, x64 et ARM64, assurez-vous que les composants
        individuels nécessaires aux deux types de cibles sont sélectionnés
        (cochés) dans la boîte de dialogue Composants individuels de
        Visual Studio Installer :

        Sous Compilateurs, outils de génération et runtimes :
            o MSVC Build Tools for ARM64/ARM64EC (Latest)
            o MSVC Build Tools for x64/x86 (Latest)

        Au besoin, vous pouvez utiliser le bouton « Modifier » de
        Visual Studio Installer pour ajouter des composants individuels
        manquants après l'installation.

        Voir :
        https://visualstudio.microsoft.com/vs/community/
  o Lua
        NetHack 5.0 pour Windows nécessite les sources de Lua, un projet
        tiers qui ne fait pas partie de la distribution ni du dépôt de
        NetHack.

        Une procédure de commandes Windows (cmd) permettant de récupérer
        les sources requises est disponible ; lancez-la comme suit depuis
        la racine de l'arborescence des sources de NetHack pour obtenir
        Lua :
            sys\windows\fetch.cmd lua
  o pdcursesmod (requis seulement si vous voulez l'interface curses)
        Si vous voulez inclure la prise en charge de l'interface curses
        dans NetHack 5.0, les sources de pdcursesmod, un projet tiers, sont
        nécessaires ; elles ne font pas partie de la distribution ni du
        dépôt de NetHack.

        Une procédure de commandes Windows (cmd) permettant de récupérer
        les sources requises est disponible ; lancez-la comme suit depuis
        la racine de l'arborescence des sources de NetHack pour obtenir
        pdcursesmod :
            sys\windows\fetch.cmd pdcursesmod

Ce processus produit un fichier zip contenant deux versions
exécutables :

    a. une version TTY et curses de NetHack dans nethack.exe ;
    b. une version graphique Windows et curses dans nethackw.exe.

/-----------------------------------------------------------\
| Compilation et exécution avec Visual Studio Community     |
\-----------------------------------------------------------/

Avec une version de Visual Studio Community, chargez dans l'IDE le
fichier de solution fourni, puis générez la solution.

Le fichier de solution Visual Studio de NetHack se trouve ici :
    sys\windows\vs\NetHack.sln

Les étapes sont les suivantes :
    1. Lancez l'IDE.
    2. Ouvrez le fichier de solution sys\windows\vs\NetHack.sln.
    3. Sélectionnez la plateforme et la configuration de génération
       voulues (x64 ou ARM64, et Release ou Debug).
       (Remarque : si vous voulez cibler ARM64 depuis une machine x64, ou
              cibler x64 depuis une machine ARM64, vous devez d'abord
              mener à bien la compilation pour la cible native de la
              machine. C'est nécessaire pour que les versions natives de
              l'hôte des outils uudecode.exe, makedefs.exe, tilemap.exe,
              tile2bmp.exe et dlb.exe soient disponibles pour les étapes
              de la compilation qui en dépendent.)
    4. Dans le menu Générer, choisissez Générer la solution.
    5. Appuyez sur F5 pour lancer le débogage.
